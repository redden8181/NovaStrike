# NOVA STRIKE — Неизвестные орбиты 3.1

## Орбиты и конструктор

Орбита 077 — домашний мир. Внизу ангара у каждого базового корабля виден закрытый
личный модуль. На ★★★ его можно установить за 4 000 монет: открывается одна из пяти
личных орбит. Остальные миры заранее не показываются в выборе маршрута.

Для повышения с ★★★ до «Алмаза» нужны монеты и 12 местных артефактов; до «Легенды» —
монеты и 30 артефактов. Оружие и корпус сначала нужно довести до текущих лимитов.
Артефакты выдаются за каждые 20 уничтожений, за элитного врага и по 3 за босса,
сохраняются сразу и не теряются при гибели. Ежедневное событие из этой экономики исключено.

Полностью прокачанный легендарный базовый корпус даёт постоянный чертёж. Во флоте
открывается отдельный конструктор: два разных чертежа, предварительный просмотр
характеристик и создание корабля за 12 000 монет. Родители и чертежи сохраняются.
Экспериментальный корабль наследует две родительские орбиты; поздние ранги требуют
артефакты обоих миров. Старые гибриды сохраняются и получают родительские технологии.

Журнал вылетов удалён из интерфейса и очищается при миграции. Сохраняются только
суммарная статистика и прогресс контрактов. Схема сохранения — v11, ключ прежний.

## iPhone

`npm run ios:sync` собирает игру и копирует её в нативный проект.
`npm run ios:open` открывает Xcode. Идентификатор приложения
`com.redden8181.novastrike` сохранён для обновления установленной версии с её прогрессом.

Мобильный космический шутер на React, TypeScript и Canvas. После первого открытия работает без сети, устанавливается как PWA. Существующие корабли, гибриды, прокачка, боссы и пять режимов сохранены.

## Обновление «Фронтир»

- Командный экран с предпросмотром выбранного корпуса и быстрым доступом к флоту, ангару и карьере.
- Четыре сектора по 45 секунд: тихая орбита, пояс обломков (волны чаще, очки целей ×1.25), магнитная туманность (радиус сбора ×1.75), ионный фронт (скорость снарядов ×1.2, очки целей ×1.5). Цикл повторяется.
- Серии уничтожений для всех кораблей: не больше 6 секунд между целями, +25% очков за каждые 5 целей, максимум ×2. Урон обрывает серию. Бонусы относятся только к обычным противникам, без умножения очков времени, боссов и стартовой точки.
- Три ежедневных контракта: уничтожения, время, босс. Прогресс складывается по завершённым вылетам. Награда получается вручную один раз за день. День определяется локальным временем устройства; это офлайн-механика, не серверный рейтинг.
- Экспорт JSON сохранения. Экспорт сохраняет резервную копию; интерфейс импорта пока не добавлен.
- В ежедневном событии отключены новые секторы, серии и прогресс контрактов, чтобы сохранить прежнюю экономику и правила.
- Обновление PWA предлагает перезагрузиться из меню и не прерывает вылет. Очистка кэша касается только кэшей NovaStrike.

## Управление

Телефон: тяни корабль пальцем, стрельба автоматическая. Способность и пауза — кнопки на экране. Клавиатура: стрелки/WASD, пробел — способность, P/Escape — пауза.

## Сохранения

Ключ `nova_strike_save_v1` остаётся прежним. Схема v10 добавляет операции; монеты, корабли, гибриды и их улучшения переносятся. Перед миграцией исходный JSON записывается в `nova_strike_save_backup_v1`; при заполненном хранилище миграция продолжает работать в памяти. Выбранный гибрид больше не заменяется на Falcon при загрузке; гибрид можно повторно выбрать во флоте.

Прогресс привязан к браузеру и адресу сайта. Не очищай данные сайта, если нужна текущая карьера. Экспорт доступен в разделе «Контракты Фронтира».

## Разработка и проверка

Node.js 22.18+ или 24:

```sh
npm ci
npm test
npm run build
npm run dev
```

Тесты проверяют серии, секторы, контракты, изоляцию ежедневного события, удаление журнала,
миграции сохранений, доступ к мирам, стоимость рангов, постоянство чертежей и создание
экспериментальных кораблей. Сборка включает строгую проверку TypeScript.
